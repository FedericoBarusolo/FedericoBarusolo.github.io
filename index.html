Navigate to any page with event information - concerts, webinars, conferences, meetups, or classes.

2

Click the Datemark extension icon and hit "Extract Events". First-time users will authenticate with Google.

3

Review Events

Datemark automatically detects all events on the page. Review and edit details as needed.

4

Add to Calendar

Select the events you want and click "Add Events to Calendar". Done!

Frequently Asked Questions

How do I add an event from a webpage to Google Calendar?

Open the page with the event, click the Datemark icon in Chrome and choose "Extract Events". Datemark detects the title, date, time and location, you review the details, and then add the event to Google Calendar with one click.

Is Datemark free?

Yes. The free tier includes 50 event extractions per month, and usage resets on the 1st of each month.

Which websites does Datemark work on?

Datemark works on any webpage that contains event information, including concert sites, newsletters, conference pages, webinar announcements, meetup listings and class schedules.

Can I add multiple events at once?

Yes. If a page lists several events, Datemark detects them all. You can select the ones you want and add them to your calendar together.

Can I edit event details before adding them?

Yes. Every detected event can be reviewed and edited before it is added, so you always stay in control of what goes into your calendar.

Is Datemark safe to use with my Google account?

Datemark connects to Google Calendar through Google's OAuth authentication. You can read more about how data is handled in our Privacy Policy.
